# Samson Design Portfolio

A responsive static portfolio site for Samson Design.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub and Vercel
1. Create a GitHub repository, e.g. `samson-design-portfolio`.
2. Upload `index.html`, the `images/` folder, and this README.
3. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
4. This is a static HTML site; no build command or framework preset is required. The free plan is subject to Vercel's current usage limits.
